# Definição de Pronto

## DoD de Agente

Missão explícita, allowlist de ferramentas, ações proibidas, saída tipada, regra de confiança/escalonamento, fallback e conjunto de avaliação.

## DoD de Pattern

Sanitizado, versionado, testado, documentado, maturidade atribuída, padrões de segurança, evals e runbook.

## DoD de Release

Eval aprovado, segurança aprovada, prontidão aprovada, rollback disponível, monitoramento ativo, dono atribuído e aprovação humana registrada.
