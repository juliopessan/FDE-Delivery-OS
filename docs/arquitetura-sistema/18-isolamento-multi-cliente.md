# Isolamento Multi-Cliente

Cada engajamento requer namespace único, armazenamento de artefatos separado, escopo de retrieval separado, credenciais separadas, tags de telemetria separadas e política de acesso explícita.

Nunca usar um único índice vetorial sem filtro para todos os clientes.

Somente ativos sanitizados/generalizados podem ser promovidos a patterns compartilhados.
