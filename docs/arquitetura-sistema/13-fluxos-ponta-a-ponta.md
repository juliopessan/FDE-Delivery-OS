# Fluxos Ponta a Ponta

## Novo Engajamento

Qualificação → Fit Score → Discovery → Pontuação de Oportunidade → Estado do Engajamento.

## Discovery ao Protótipo

Reunião/Documentos → Requisitos → Casamento de Patterns → Spec de Solução → Revisão do FDE → Scaffold → Protótipo.

## Protótipo à Produção

Protótipo → Golden Set → Evals Funcionais/Segurança/Custo → Guardrails → Prontidão → Aprovação Humana → Deploy.

## Incidente

Alerta → Coleta de Traces → Diff de Release → Ranking de Hipóteses → Mitigação Segura → Verificação → Postmortem.

## Engenharia Composta

Ativo do Cliente → Sanitizar → Generalizar → Testar → Revisão de Segurança → PR do Pattern → Biblioteca Compartilhada.
