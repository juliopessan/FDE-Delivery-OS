# End-to-End Flows

## New Engagement

Qualification → Fit Score → Discovery → Opportunity Scoring → Engagement State.

## Discovery to Prototype

Meeting/Documents → Requirements → Pattern Matching → Solution Spec → FDE Review → Scaffold → Prototype.

## Prototype to Production

Prototype → Golden Set → Functional/Security/Cost Evals → Guardrails → Readiness → Human Approval → Deploy.

## Incident

Alert → Trace Collection → Release Diff → Hypothesis Ranking → Safe Mitigation → Verification → Postmortem.

## Compound Engineering

Client Asset → Sanitise → Generalise → Test → Security Review → Pattern PR → Shared Library.
