# Definition of Done

## Agent DoD

Explicit mission, tool allowlist, forbidden actions, typed output, confidence and escalation rule, fallback, and an evaluation set.

## Pattern DoD

Sanitised, versioned, tested, documented, maturity assigned, security defaults, evals and a runbook.

## Release DoD

Eval passed, security passed, readiness passed, rollback available, monitoring active, owner assigned, and human approval recorded.
